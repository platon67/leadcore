# Skills issues de `agentic-awesome-skills`

Source : <https://github.com/sickn33/agentic-awesome-skills>
Licence : MIT pour le code, CC BY 4.0 pour le contenu rédactionnel.

Le dépôt d'origine porte plus de 2 100 skills et 23 000 fichiers. On n'en a
recopié que cinq, celles qui servent au travail sur `site/` et `deck/` :

| Skill | Ce qu'elle apporte |
|---|---|
| `scroll-experience` | grammaire des animations liées au défilement : révélation, épinglage, parallaxe, défilement horizontal, budgets de performance |
| `anti-ui-slop` | les marqueurs d'interface générée sans intention, et comment les éviter |
| `fixing-motion-performance` | diagnostic des animations qui saccadent, propriétés composées, budget d'images |
| `high-end-visual-design` | hiérarchie, échelle, densité, traitement de la lumière |
| `design-spells` | micro-interactions réutilisables |

Pour en ajouter une autre : `git clone --depth 1` le dépôt, copier
`skills/<nom>/` dans ce dossier, et compléter le tableau ci-dessus.
